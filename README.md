# Troy-Ashton-REPO
Purpose of Repository
This repository was created to confirm completion of Tutorial Task #4 Part A and to demonstrate the use of Git and GitHub version control features, including branching, commits, pull requests, collaboration, code review, and merging.

Steps Followed to Complete the Tutorial
Step 1: Install Git and Create a GitHub Account
Installed Git on the local machine.
Created/logged into a GitHub account.
Step 2: Create a Local Git Repository
Created a new local Git repository on the computer.
Initialized the repository using Git.
Step 3: Add a Collaborator
Selected a classmate as a collaborator.
Added the collaborator to the GitHub repository through the repository settings.
Step 4: Create a New Branch
Created a new branch to make changes without affecting the main branch.
Step 5: Add a New File
Added a new file to the repository (sample text/Python file containing my first and last names).
Step 6: Commit the New File
Committed the file with a clear commit message:
"Added sample file for tutorial"
Step 7: Push the Branch to GitHub
Pushed the newly created branch from the local repository to GitHub.
Step 8: Create a Pull Request
Opened a Pull Request (PR) from the new branch into the main branch.
Assigned the collaborator as the reviewer.
Step 9: Review and Approval
Collaborator reviewed the Pull Request and provided approval.
Step 10: Merge into Main Branch
Merged the approved branch into the main branch after successful review.
